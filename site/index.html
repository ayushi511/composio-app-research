How This File Was Compiled

The agent, and where it needed a human

01

Input

100 apps, pre-sorted into 10 categories with a name and a hint URL — no other context given to the model.

02

Schema lock

A strict JSON schema (auth, access model, API surface, buildability, blocker, evidence, confidence) written before any research began.

03

Agent pass

Each app run through an LLM prompted to return only schema-conformant JSON, citing real evidence URLs and self-rating confidence.

04

Parse & retry

Output validated as JSON; malformed or failed calls logged and automatically retried rather than silently dropped.

05

Link audit

Every cited evidence URL fetched over HTTP to check it actually resolves — a free, automated first accuracy signal.

06

Human check

The highest-risk apps (by dead-link count) reviewed by hand against real developer docs and corrected where wrong.

Engineering log — three pivots forced by real constraints

  1. Search grounding needed billing. The first model choice offered live web search, but the grounding tool required a billing-enabled project even on the "free" tier — ruled out under a no-spend constraint, so the pipeline runs on model knowledge rather than live search.
  2. The flagship free tier capped at 20 requests/day. The first working model hit a hard daily quota after ~19 apps — not a rate-limit backoff, a wall. Required migrating providers mid-run rather than waiting a day.
  3. The replacement's "compound" mode rejected the payload. A multi-tool system model returned 413 Request Entity Too Large on the very first call; switching to a plain production model and shrinking the prompt (dropping the full pretty-printed schema from every request) fixed it.
  • The access-model taxonomy (5 buckets instead of a self-serve/gated binary) was a judgment call made after seeing Salesforce: free for a dev trial, but paid in production — a binary field couldn't capture that.
  • Two of 100 apps threw hard pipeline errors (a token-budget collision on iPayX, and a tool-call the model attempted that wasn't wired up for NotebookLM) — both required a human to diagnose and re-run with a corrected prompt.
  • The final pattern narrative — which categories cluster where, which blocker dominates — was written by a person reading the computed distributions, not generated by the agent.
